# CyberGuard

CyberGuard é um aplicativo web projetado para aumentar a conscientização sobre segurança cibernética nas empresas. Através de um sistema de perguntas e respostas, os usuários podem testar seus conhecimentos e ganhar pontos com base em suas respostas.


## Funcionalidades

Perguntas de múltipla escolha: Teste seus conhecimentos com perguntas sobre segurança cibernética.

Sistema de pontuação: Ganhe pontos com base nas suas respostas corretas.

Futuras atualizações: Planejamos adicionar perguntas abertas e outros tipos de interação.
